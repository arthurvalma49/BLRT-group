## 2. General Information

BLRT Grupp is one of the largest industrial groups in the Baltic Sea region, uniting more than 50 companies in Estonia, Lithuania, Latvia, Finland, Poland, Ukraine and Brazil.

**Main business areas:**
- Shipbuilding
- Ship repair
- High-technology equipment and metal structures manufacturing
- Metal and metal products processing and sales
- Mechanical engineering
- Transport services and equipment rental
- Port and stevedoring services
- Industrial and medical gas production and sales
- Foundry
- Real estate development

Currently the group's companies are represented by more than 24 websites built on WordPress. The number of websites may increase as the business develops.

Despite the different activities of the group's companies, most websites have a similar structure and contain the same typical information blocks: company introduction, services, projects, news, job offers, and contact details.

The current design of the websites is outdated and needs to be updated. A modern solution is needed that matches the scale and level of BLRT Grupp, ensures a convenient user experience, and helps to form a unified corporate visual identity.

---

## 3. Project Goals

- Develop a modern design and universal WordPress theme for all BLRT Grupp company websites.
- The new design and WordPress theme must become the unified standard for existing and future websites.
- Create a new design concept reflecting the scale, professionalism, and activity specifics of the group's companies.
- Develop a universal WordPress theme usable on both existing and future BLRT Grupp websites.

## 6. Project Scope

### 6.1 Preparatory stage
- Analyse BLRT Grupp's existing websites
- Study structure, content, and functional capabilities
- Identify common requirements, typical pages, and functional elements
- Prepare recommendations for unifying structure, navigation, and UX
- Form the concept of a universal solution suitable for most group company websites

### 6.2 Design concept development
- Develop a unified design concept for all group websites
- Design adaptive layouts for main pages and user journeys
- Create a unified set of typical elements and content blocks for use across all websites

### 6.3 WordPress theme development
- Implement the approved design as adaptive HTML/CSS/JavaScript
- Develop a universal WordPress theme based on the approved design concept
- Implement typical content blocks and page templates for publishing different content types (news, projects, jobs, services, contacts, etc.)
- Implement necessary theme settings via the WordPress admin panel

### 6.4 Testing and handover
- Test the developed solution
- Fix deficiencies identified during testing
- Prepare documentation for using and configuring the WordPress theme
- Hand over all source files, materials, and work results to the client

**Deliverables:** Approved design concept, set of design mockups, adaptive HTML/CSS/JavaScript implementation, universal WordPress theme, usage documentation, and all source files.

---

## 7. Additional Requirements

- Design must be based on the structure and content of existing BLRT Grupp websites.
- Current websites use multiple language versions: **English, Estonian, Russian, Lithuanian, Latvian, Finnish, Polish**.
- Chosen fonts and design solutions must support correct display of all used languages and special characters.
- WordPress theme development should, where possible, account for existing plugins and solutions used on current group websites.
- Creation of new text content, translation, and editorial work are **outside the project scope**. Replacement of photos, graphic materials, and individual content elements may be agreed between parties.
- WordPress theme must comply with basic **SEO requirements**: correct page title structure, SEO plugin support, multilingual support, metadata, and search engine indexing options.

---

## 8. WordPress Theme Requirements

The WordPress theme must allow management of main website settings via the WordPress admin panel without changing the code.

### The theme must support:
- Setting logos, company identity images, and other design elements
- Managing display of individual blocks and sections
- Typical content blocks and page templates, including:
  - **Sliders and banners**
  - **Video blocks**
  - **Text blocks**
  - **Image galleries**
  - **Service cards**
  - **Product cards**
  - **Project cards**
  - **News blocks**
  - **Job listing blocks**
  - **Contact forms**
  - **Maps and contact details**
  - **Certificate blocks**
  - **Tables and technical data**
- Setting the structure of the home page and other typical pages
- Customising the visual appearance of the website for different group companies while maintaining a unified corporate style

### Required plugin compatibility:
- **WPML Multilingual CMS**
- **Advanced Custom Fields PRO (ACF PRO)**

These plugins are already used on existing websites. Additional plugins may be used if needed to implement theme functionality.
